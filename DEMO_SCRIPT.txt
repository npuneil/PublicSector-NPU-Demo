EXECUTIVE Q&A – ANTICIPATED QUESTIONS & ANSWERS
══════════════════════════════════════════════════════════════════════════════

  Q: "How does PII detection work?"
  A: "Pattern matching runs locally before any routing decision. It
     detects SSNs, phone numbers, email addresses, physical addresses,
     dates of birth, case numbers, and license numbers. If any PII is
     found, the request is forced to local processing. The system is
     fail-closed — if it's uncertain, it defaults to local."

  Q: "What about CJIS / FedRAMP compliance?"
  A: "On-device processing means data doesn't leave the device — that
     simplifies compliance significantly. For cloud routing, only
     sanitized, PII-free content is sent to Azure OpenAI, which
     supports FedRAMP and government cloud regions."

  Q: "Can staff override the routing?"
  A: "Yes. There's a 'Mark Sensitive' toggle that forces local
     processing regardless of PII detection. And a 'Force Local' toggle
     for full manual control. But PII detection can't be overridden —
     if PII is found, it's always local."

  Q: "What happens in disaster scenarios?"
  A: "The Disaster Response module is always local-only by policy.
     Summaries and metadata are queued for sync when connectivity
     returns. No citizen data or sensitive field notes leave the device."

  Q: "How accurate is the on-device model vs cloud?"
  A: "The on-device model handles routine tasks: summarization, data
     extraction, drafting responses, translating notes. Think of it as
     your first-line AI for the 80% of daily tasks. Complex policy
     analysis or cross-department coordination benefits from cloud."

  Q: "What Intel hardware does this need?"
  A: "Any Intel Core Ultra Copilot+ PC. The NPU is built into the
     processor — no add-on needed. If you're already purchasing
     Copilot+ PCs, the AI capability is included."

  Q: "What about the audit trail?"
  A: "Every routing decision is logged to a local SQLite database:
     module, route (local/cloud), reason code, token count, latency.
     No raw prompts or citizen data are stored — only metadata.
     This supports compliance and oversight requirements."

DEMO TIPS

    like 123-45-6789 and watch it intercept. Very visual.

  • If asked for more, show Policy Analyzer with the sample ordinance —
    point out it catches the "[INTERNAL NOTE]" as sensitive.

  • The dashboard projection calculator is interactive — let stakeholders
    adjust numbers for their own agency scale.
  • If cloud is not configured, focus on local-only value: privacy,
    offline, cost, and mention cloud as "available when needed."
